# 行业资金四象限

每个行业按"短期（近20日）× 长期（近250日，历史不足时用120日）"的主力净流入占成交额比例，分入四个象限，页面主图是四象限散点图（横轴长期、纵轴短期，一个点一个行业，点击查看详情）；前三类附行业内个股主力净流入TOP3（按5/20/60/120/250日窗口排名，页面上可点击切换），并用行业ETF份额变化做验证。

## 部署（全免费）

1. 新建一个**公开**GitHub仓库，把本目录全部文件推上去（私有仓库的Pages需付费）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/docs`。
3. Actions 页面手动运行一次 `update-sector-flow`，mode 填 `final`。首次会逐个行业拉取约120个交易日历史，需要几分钟。
3b. （建议）再手动运行一次，mode 填 `backfill`，回填个股约120个交易日历史，约1~2小时。不回填也能用，但个股的20/60/120/250日榜要靠每天累积，未满窗口的卡片会提示"仅累积N日"。回填期间定时任务会排队等待。
4. 访问 `https://<用户名>.github.io/<仓库名>/`，电脑和手机同一个链接。

## 运行节奏（北京时间）

| 时间 | 模式 | 作用 |
|---|---|---|
| 交易日 09:00–14:59，每15分钟 | intraday | 今日暂计，不写历史 |
| 15:30 | final | 刷新历史并定稿 |
| 19:30 | etf | 记录ETF份额快照，刷新验证 |

GitHub Actions 的定时任务可能延迟几分钟到十几分钟，高峰期偶尔漏跑，页面顶部显示最后更新时间。

## 需要知道的限制

- 主力净流入是大单口径的估算值，只适合看相对强弱和方向，不是真实资金存量。
- 卡片右侧"所选周期的涨幅"来自东方财富行业板块指数日K（`data/industry_price.csv`，首次约回溯430个自然日，之后每天补最近几天）；行业名需与资金流行业名一致，取不到时显示"—"。涨幅和金额都随页面顶部的周期按钮切换。
- 个股逐日主力净流入存在 `data/stock_daily/`，每个交易日一个压缩文件（约100KB），只追加不改写旧文件，一年约25MB。
- 东方财富历史接口约回溯120个交易日。250日窗口从首次运行起逐日累积，**满约一年前，长期方向用120日**，卡片上会标注。
- ETF验证依赖自己积累份额快照，运行满20个交易日后才开始出结果，之前显示"ETF数据积累中"。`etf_map.json` 里的行业名和ETF代码请自行核对。
- AKShare 接口偶尔改版或限流，抓取失败时会保留上一次数据并在日志里打印 warning。

## 本地自测

```bash
pip install -r requirements.txt
python run.py demo     # 模拟数据，不联网，生成 docs/index.html
python run.py final    # 真实数据（需能访问东方财富）
```
