# 行业资金四象限

数据源：新浪财经（主力净流入，大单口径）。行业按新浪行业分类（48个）；每个行业的资金流由行业内个股逐日汇总得出。

页面包含：
- **各周期资金流入/流出最多的行业 TOP3**：堆叠条形图，横轴为周期（20/60/120/250日），柱向上＝净流入最多的3个行业叠成，柱向下＝净流出最多的3个行业叠成，同一纵轴比例尺；行业名称、金额、占比在悬停/点按浮窗里
- **四象限散点图**：横轴长期（近250日，历史不足时用120日）、纵轴短期（近20日）的主力净流入占同期成交额比例，一个点一个行业，点击查看详情
- **行业详情**：所选周期的主力净流入金额与占比；前三类象限附行业内个股主力净流入TOP3；行业ETF份额变化验证

## 部署（全免费）

1. 新建一个**公开**GitHub仓库，把本目录全部文件推上去（私有仓库的Pages需付费）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/docs`。
3. Actions → `update-sector-flow` → Run workflow：
   - 先运行 `probe`（约1分钟）：自检新浪数据源是否可用；
   - **再运行 `backfill`（约20~40分钟，只需一次）**：回填约320个交易日的个股历史。没有这一步，页面没有历史可算；
   - 最后运行 `final`（交易日15:30之后）：生成第一份页面。
4. 访问 `https://<用户名>.github.io/<仓库名>/`，电脑和手机同一个链接。

## 运行节奏（北京时间，交易日）

| 时间 | 模式 | 作用 |
|---|---|---|
| 09:00–14:59，每15分钟 | intraday | 今日暂计，不写历史 |
| 15:30 | final | 保存当日个股数据并定稿 |
| 19:30 | etf | 记录ETF份额快照，刷新验证 |

GitHub Actions 的定时任务可能延迟几分钟到十几分钟，高峰期偶尔漏跑，页面顶部显示最后更新时间。

## 需要知道的限制

- 主力净流入是新浪大单口径的估算值，只适合看相对强弱和方向，不是真实资金存量。与东方财富、同花顺的"主力"口径不同，数值不可直接对比。
- 行业历史没有现成接口，是由个股逐日数据汇总出来的：行业主力净流入 = 行业内个股主力净流入之和；占比 = 净流入合计 ÷ 成交额合计。个股成交额由"净额 ÷ 净占比"反推，占比接近0的个别个股当日不计入成交额，影响很小。
- 个股逐日数据存在 `data/stock_daily/`，每个交易日一个压缩文件（约100KB），只追加不改写旧文件，一年约25MB。
- 只统计沪深A股，不含北交所；基金、ETF 已过滤。
- ETF验证依赖自己积累份额快照，运行满20个交易日后才开始出结果，之前显示"ETF数据积累中"。`etf_map.json` 里的行业名要与新浪行业名一致，ETF代码请自行核对。
- 数据源接口是公开网页接口，可能改版或限流；抓取失败时会报错中止而不是写入残缺数据。

## 本地自测

```bash
pip install -r requirements.txt
python run.py demo     # 模拟数据，不联网，生成 docs/index.html
python run.py probe    # 自检新浪数据源（需能访问新浪）
```
